## 📌 프로젝트 소개

`프로젝트명`은 정해진 경로를 따라 이동하는 몬스터를 다양한 타워로 막아내는
**3D 타워 디펜스 게임**입니다.

플레이어는 제한된 재화를 활용하여 타워를 건설하고, 각 타워의 공격 방식과 특성을 조합해 스테이지를 공략해야 합니다.

### 주요 특징

* 다양한 공격 방식을 가진 타워
* 일반 공격, 범위 공격, 지속 피해, 둔화 및 기절 효과
* 웨이브 기반 몬스터 스폰 시스템
* 타워 건설 및 철거 시스템
* 타겟 우선순위 변경 시스템
* Object Pooling을 활용한 최적화
* ScriptableObject 기반 데이터 관리
* Addressables 기반 리소스 로딩

<br>

## 🕹️ 게임 플레이

플레이어는 맵의 지정된 위치에 타워를 건설할 수 있습니다.

각 타워는 공격 범위 안에 들어온 적을 자동으로 탐색하며, 설정된 타겟 우선순위에 따라 공격합니다.

모든 몬스터가 목적지에 도달하기 전에 처치하면 웨이브를 방어할 수 있습니다.

<br>

## ⌨️ 조작 방법

| 조작       | 키                  | 설명                       |
| -------- | ------------------ | ------------------------ |
| 화면 이동    | `W`, `A`, `S`, `D` | 카메라를 상하좌우로 이동합니다.        |
| 화면 회전    | 마우스 우클릭 드래그        | 카메라 시점을 회전합니다.           |
| 확대 및 축소  | 마우스 휠              | 카메라 거리를 조절합니다.           |
| 타워 선택    | 마우스 좌클릭            | 건설할 타워 또는 배치된 타워를 선택합니다. |
| 타워 건설    | 마우스 좌클릭            | 선택한 위치에 타워를 설치합니다.       |
| 타워 선택 해제 | 마우스 우클릭            | 현재 선택을 취소합니다.            |
| 일시 정지    | `ESC`              | 일시 정지 메뉴를 엽니다.           |

> 실제 프로젝트의 입력 방식에 맞게 키를 수정하세요.

## 🏰 타워 종류

### 일반 타워

단일 적을 대상으로 투사체를 발사합니다.

* 빠른 공격 속도
* 안정적인 단일 대상 공격
* 가장 기본적인 타워

### 화염 타워

범위 안에 있는 적에게 지속 피해를 줍니다.

* 지속 피해
* 다수의 적 공격 가능
* 적을 따라가는 화염 이펙트

### 둔화 타워

공격에 적중한 몬스터의 이동 속도를 감소시킵니다.

* 이동 속도 감소
* 다른 공격 타워와 조합 가능
* 웨이브 진행 속도 제어

### 기절 타워

일정 확률 또는 공격 주기에 따라 적의 움직임을 멈춥니다.

* 적 행동 제한
* 강한 몬스터 대응
* 범위 제어에 효과적

### 곡사포 타워

목표 지점을 예측하여 범위 공격을 실행합니다.

* 넓은 범위 피해
* 타겟의 이동 위치 예측
* 밀집된 적에게 효과적

## ⚙️ 주요 구현 기능

### Object Pooling

투사체, 공격 범위, 파티클 이펙트를 반복적으로 생성하고 제거할 때 발생하는 부하를 줄이기 위해 오브젝트 풀링을 적용했습니다.

```csharp
PoolableObject pooledObject = ObjectPoolManager.Instance.Spawn<PoolableObject>(
    prefab,
    spawnPosition,
    spawnRotation,
    parent
);
```

사용이 끝난 오브젝트는 `Destroy`하지 않고 풀로 반환합니다.

```csharp
ObjectPoolManager.Instance.Despawn(pooledObject);
```

### ScriptableObject 데이터 관리

타워, 투사체, 공격 범위, 이펙트 데이터를 ScriptableObject로 분리했습니다.

이를 통해 코드 수정 없이 인스펙터에서 다음 값을 조절할 수 있습니다.

* 공격력
* 공격 속도
* 공격 범위
* 투사체 속도
* 상태 이상 지속 시간
* 사용 이펙트
* 사용 사운드

### 타겟 우선순위 시스템

타워마다 서로 다른 방식으로 공격 대상을 선택할 수 있습니다.

* 타워와 가장 가까운 적
* 타워에서 가장 먼 적
* 목적지에 가장 가까운 적
* 목적지에서 가장 먼 적
* 체력이 가장 높은 적
* 체력이 가장 낮은 적

### Addressables 리소스 관리

타워 공격에 사용되는 투사체, HitBox, 이펙트 및 사운드 리소스를 Addressables로 관리했습니다.

필요한 리소스를 미리 로드하고 Object Pool과 연동하여 반복적인 로딩을 최소화했습니다.

## 🔧 트러블 슈팅

### 지속 공격 이펙트가 즉시 사라지는 문제

**문제**

화염 타워가 추적하던 몬스터가 사망하거나 공격 범위를 벗어날 경우, 파티클 애니메이션이 끝나기 전에 이펙트가 즉시 풀로 반환되었습니다.

**원인**

타겟 유효성 검사에 실패하는 즉시 HitBox와 연결된 이펙트를 함께 반환하고 있었습니다.

**해결**

공격 판정과 이펙트 생명주기를 분리하고, 파티클 재생 종료 시점 또는 설정된 지연 시간 이후 풀로 반환하도록 수정했습니다.

---

### 사망한 몬스터를 계속 추적하는 문제

**문제**

몬스터의 사망 애니메이션이 재생되는 동안 타워가 해당 몬스터를 계속 공격 대상으로 선택했습니다.

**원인**

게임 오브젝트가 비활성화되는 시점을 기준으로 생존 여부를 판단하고 있었습니다.

**해결**

몬스터의 `isDead` 값을 타겟 정보에 즉시 반영하고, 타겟 탐색 과정에서 사망 상태의 몬스터를 제외했습니다.

---

### 반복적인 생성으로 인한 성능 저하

**문제**

다수의 투사체와 파티클이 생성되는 웨이브에서 프레임 저하가 발생했습니다.

**원인**

공격할 때마다 `Instantiate`와 `Destroy`가 반복되어 메모리 할당과 GC가 발생했습니다.

**해결**

투사체, HitBox, 파티클 이펙트를 Object Pool로 통합하여 재사용하도록 변경했습니다.
